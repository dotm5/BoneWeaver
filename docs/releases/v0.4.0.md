# BoneWeaver v0.4.0 — Three Force-complete Automatic Modes

BoneWeaver now exposes three top-level one-click actions:

- the original UEFormat-compatible whole-Armature conversion;

- link-only native-chain rebuilding for already well-oriented rigs;

- an experimental hybrid that accepts confident multi-feature results per bone
  and automatically keeps the UEFormat-compatible fallback for every unresolved
  bone.

No recognition result can block the hybrid workflow. Invalid vectors,
low-confidence terminals, ambiguous branches, missing proposals, and even a
complete precision-planner exception become advisory fallback evidence. All
three modes keep the v0.3.1 force-complete transaction, persistent Snapshot,
mode-specific idempotence, conflict-aware exact Restore, and native Blender `L`
selection behavior.
