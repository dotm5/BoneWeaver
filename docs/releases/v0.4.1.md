# BoneWeaver v0.4.1 — Rest-basis and Animation Compatibility

BoneWeaver 0.4.1 keeps all three v0.4.0 automatic modes and adds one shared
rest-basis transaction for Quick Original, Links Only, Hybrid, and scoped Apply.

## Changes

- Compute rest-basis deltas in each bone's parent-local coordinate system.
- Compose UEFormat `post_quat` cumulatively and include basis metadata in exact
  rollback and Restore snapshots.
- Sample and rebase one safe, unshared Active Action so evaluated poses at the
  sampled key and handle times remain unchanged.
- Preserve connected-child topology while an Action is rebased.
- Block active NLA strips, pose-bone Drivers, effective pose constraints, shared
  Actions, missing bones, and unsupported Action paths or properties.
- Use the legacy Quick transaction as an explicit safe fallback when an Active
  Action has no keyed pose-bone curves.
- Preserve Hybrid multi-feature proposals and its per-bone UEFormat fallback.

## Automatic modes retained

- `boneweaver.quick_reorient_auto`
- `boneweaver.quick_reorient_links_only`
- `boneweaver.quick_reorient_hybrid_auto`
