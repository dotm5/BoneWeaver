# BoneWeaver v0.3.1 — Force-complete One-click Conversion

## What changed

The panel-top **全自动转换并重建 L 键骨链** action now starts immediately and
must not stop on workflow policy checks. The confirmation dialog was removed.
Action, NLA, Driver, bone/object Constraint, non-identity Pose, B-Bone segments,
Bone parenting, envelope deformation, duplicate Armature modifiers, transform
conditions, and mesh diagnostics are advisory only.

Shared Armature data is made single-user before planning. Linked data is
localized when Blender permits it. Mesh and neutral-evaluation diagnostics are
best-effort: skipped or failed diagnostics are recorded in the Snapshot and UI
summary but do not roll back a completed conversion. Actual Blender edit
exceptions still roll back to avoid a half-mutated Armature.

The separate scoped Physics Graph Apply retains its original strict safety
contract.

## Installation

Download `boneweaver-0.3.1.zip`, then use **Edit > Preferences > Extensions >
Install from Disk** in Blender 4.2 or newer.
