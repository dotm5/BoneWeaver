# BoneWeaver v0.2.0 — Initial Public Preview

## Highlights

- Read-only hierarchy inspection with Parent/Root/Descendant overlays and
  explicit branch continuation.
- Confirmed semantic discovery for secondary-motion chains.
- Immutable Physics Graph planning, preview, conservative terminal inference,
  and opt-in visual chain cleanup.
- BoneX and Wiggle-oriented rotation/stretch profiles without proxy-bone or
  weight mutations.

## Safety and data integrity

Analyze, inspection, and discovery do not modify rest geometry. Apply is limited
to selected EditBone `tail`, `roll`, and `use_connect`, requires a current frozen
plan, writes a persistent Snapshot, records a mutation ledger, validates neutral
evaluated meshes, and rolls back on failure. Export is gated and independently
reopened in a second Blender process before success is reported.

## Installation

Download `boneweaver-0.2.0.zip`, then use **Edit > Preferences > Extensions >
Install from Disk** in Blender 4.2 or newer. No external Python dependencies are
required.

## Validation evidence

- Blender 5.2.0 LTS RC build `710df102694f`.
- 208/208 Blender-hosted automated tests passed.
- A real UE asset containing 157 bones and 25,610 vertices completed Analyze,
  Apply, export, and independent reopen validation.
- The packaged extension passed an isolated installation and repeated
  registration/unregistration cycle.

## Known limitations

- BoneWeaver prepares physics chains; it does not retarget UE animation bases.
- Blender 4.2 is the manifest minimum; local release validation used the Blender
  5.2 build above.
- BoneX and Wiggle behavior remains dependent on project-specific physics tuning.
- Unsafe Actions, NLA, drivers, constraints, pose state, branch ambiguity, and
  low-confidence terminal evidence intentionally block Apply.
