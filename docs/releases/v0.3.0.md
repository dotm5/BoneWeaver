# BoneWeaver v0.3.0 — One-click Native Linked Reorientation

## Highlights

- Added a panel-top **全自动转换并重建 L 键骨链** button that completes
  whole-Armature conversion, native hierarchy reconstruction, validation, and
  Snapshot creation in one confirmed operation.
- Added clean-room UEFormat-compatible reorientation for importer metadata,
  already-reoriented UEFormat data, and generic joint hierarchies.
- Rebuilds safe maximal linear segments with native Blender connectivity so the
  Edit Mode `L` key works on finger, hair, ribbon, spine, and similar chains.
- Keeps branches, Socket bones, controls, and unsafe boundaries disconnected.
- Added exact conflict-aware Restore, idempotence, automatic rollback, and
  whole-Armature/mesh invariants.

## Safety and data integrity

The action may change only EditBone `tail`, `roll`, and `use_connect`. It does
not change heads, parents, names, weights, meshes, modifiers, animation data,
constraints, drivers, or UEFormat animation metadata. A persistent Snapshot is
written before mutation. Post-validation failure restores the original state;
manual edits after a successful conversion cause Restore to refuse the
overwrite.

## Installation

Download `boneweaver-0.3.0.zip`, then use **Edit > Preferences > Extensions >
Install from Disk** in Blender 4.2 or newer. No external Python dependencies are
required.

## Validation evidence

- Blender 5.2.0 LTS RC build `710df102694f`.
- 220/220 Blender-hosted automated tests passed.
- Compared 154 eligible bones against UEFormat 1.0.0 at fixed commit
  `8da96d65f669ca688dbf7c0141f800605a6c16e6`: maximum direction error
  `0.033878443821242374°`, maximum length error `1.1644113720454818e-7`,
  maximum Head and Socket error `0`, and no parent differences.
- A raw 157-bone `.uemodel` completed one-click conversion, native `L`
  selection checks on finger/hair/ribbon/spine components, idempotent second
  execution, and exact Restore without changing its source hash.
- Existing `x1.blend` completed the same acceptance path under
  `--factory-startup`; its source hash also remained unchanged.
- The packaged extension passed isolated installation and three repeated
  unregister/register cycles.

## Known limitations

- The tool changes rest-bone display orientation but does not rewrite UEFormat
  `post_quat` animation metadata or retarget animation bases.
- Branches intentionally delimit native linked components.
- Blender 4.2 is the manifest minimum; local executable validation used the
  Blender 5.2 build above.
